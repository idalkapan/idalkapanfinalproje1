# Participant Management System

A simple participant management system developed with Python.

## Features

* Add new participants
* View participant information
* Generate login codes and passwords
* Store data using text files

## Technologies

* Python
* File Handling
* Modular Programming

## Project Files

```bash
main.py
islemler.py
MuhendisFest2024-Katilimcilar.txt
girisKodu_sifre.txt
```

## Run the Project

```bash
python main.py
```

## Example Menu

```text
1. Add new participant
2. View participant information
3. Generate login code and password
4. Exit
```

## Purpose

This project was developed to practice Python fundamentals, file operations, and modular programming.
